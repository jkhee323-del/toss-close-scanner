# Toss Close Scanner — 2026-11-22 최종 개발·검증 현황

## 결론

운영 스캐너의 가격 오염·자동갱신 안전성·기존 매매 모델 검증은 마무리했다.
다만 **프로젝트의 모든 데이터 및 예측 기능이 완료된 것은 아니다**.
원천 데이터 권한, 과거 KRX 이상 시세의 독립 검증, 실시간 CVD,
예측력 우위 입증 및 호스팅 사이트 육안 검사는 별도 승인 조건이다.

## 운영에 반영한 변경

1. 한국 주식 자동갱신은 KRX 가격 수집 실패 시 `FinanceDataReader`의
   `NAVER:종목코드`를 검증된 **대체 일봉 공급원**으로 시도한다.
2. 저장된 거래일의 종가와 새 공급원 가격이 3거래일 이상 일치해야 한다.
   하나라도 기존 수정주가 기준과 1% 이상 다르면 공급원을 거부한다.
3. 공급원이 비정상 0원/중복 날짜/시고저종 불일치 자료를 반환하면 거부한다.
   저장된 과거 가격은 덮어쓰지 않고 **새로 완료된 거래일만 추가**한다.
4. 장중 미완성 일봉은 공급원 조회 실패 여부와 관계없이 제거한다.
5. 최근 데이터가 장기간 뒤처지는 종목 비율이 높으면 갱신 자체를
   실패 처리한다. 오래된 캐시를 새 데이터처럼 표시하지 않는다.
6. 운영 스모크 검사는 한국 종가매매 모델/4개 날짜 탭,
   해외 81개 시세 CSV와 56개 후보 가격 일치, 데이터 형식을 확인한다.

## 2026-11-22 실제 검증

- 독립 NAVER 공급원은 삼성전자 최근 **20개 거래일** 종가가
  기존 저장 데이터와 모두 일치했다.
- 한국 대형주 6개 종목에서 **1일을 삭제한 임시 시세**를
  KRX 없이 NAVER로 복원했고 모두 기존 마지막 거래일 종가와 일치했다.
- 코드 구간에 치우치지 않게 선정한 **60개 한국 종목**에서도
  **60/60개** 마지막 완료 일봉 복원이 성공했다.
- `accuracy-lab`은 수정된 데이터 수집/검증 경로에 대해
  **89개 회귀 테스트 통과**.
- `main`은 **27개 운영 테스트 통과**,
  한국 분석 가능 종목 495개, 제외 4개, 최근 정상 구간으로 복구한 45개,
  해외 데이터 81개, 해외 후보 56행, 날짜 탭 4개 정상이다.
- 해당 일자 기준 최신으로 확인한 한국/미국 저장 거래일은
  **2026-11-20**이다. 미국과 한국 시장 시간대/휴장일은 별도 고려한다.

## 반드시 남기는 외부 의존성

- **KRX 과거 자료와 외국인·기관 수급:** 49개 과거 파일,
  약 1,847개 비정상 행은 KRX 로그인 실패 때문에 검증된 수정값이
  없다. NAVER 독립 가격 검사도 과거 8개 파일에서 신뢰 가능한
  대체값을 제시하지 못했다. 0원은 임의 주가로 바꾸지 않는다.
  본인 KRX 허가 계정이 있으면 GitHub Actions secrets에
  `KRX_ID`와 `KRX_PW`를 등록하고 수동 검증 워크플로를 실행한다.
- **자동 진짜 CVD:** 시장 미시구조상 매수/매도 주도 체결 기록이 있는
  합법적 데이터 공급원과 이용권한 없이는 계산할 수 없다.
- **모델 성능:** 예비 백테스트 수익률을 실거래 또는 보정된
  상승확률이라 주장하지 않는다. 독립적인 향후 기간 검증이 필요하다.
- **호스팅 UI:** GitHub 스모크와 실제 브라우저 접속 확인은 별개다.
