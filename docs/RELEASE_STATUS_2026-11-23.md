# Toss Close Scanner — 2026-11-23 운영 인수인계

## 적용된 코드와 실제 확인한 결과

**운영 브랜치: `main`.** 실험용 장기 AI 확률 모델은 반영하지 않았다.

### 1. 한국 시세 자동갱신 복구

- 2026-11-23 한국 시장은 정상 거래일이었지만 기존 기본 자동갱신 실행이 보이지 않아
  삼성전자·SK하이닉스 저장 시세가 11월 20일에 머문 것을 발견했다.
- `src/kr_refresh_watchdog.py`는 독립 NAVER 시세로 완료 거래일이 있는지
  비교한다. 기존 종가가 3개 거래일 이상 일치하지 않으면 새 자료를
  승인하지 않는다. 미완성 거래일/잘못된 가격은 받아들이지 않는다.
- `update-korea-backup.yml`은 월~금 **20:45 KST(11:45 UTC)** 보조 일정으로
  새 거래일이 빠졌을 때만 갱신을 재시도하도록 추가했다.
- 첫 실행은 예약이 아니라 **워크플로 파일 반영으로 즉시 시작**되었다.
  **GitHub Actions 45191914242 성공**: 한국 499개 파일 가운데
  **496개 파일에 11월 23일 거래일 반영**, 3개는 공급원 검증 실패로
  기존 시세를 보존했다. 데이터는 `main`과 `accuracy-lab`에 저장되었다.
- 삼성전자와 SK하이닉스 저장 날짜가 11월 23일까지 실제 변경되었으며,
  감시기가 이후 `needs_refresh=false`로 재확인했다.
- 다음 예약 시점의 자동 실행 성공은 **아직 실제로 관측되지 않았다**.
  GitHub schedule은 지연 또는 누락될 수 있다.

### 2. 스캐너와 데이터 품질

- 기존 단기 HGB 매매 모델의 점수 계산 방식은 바꾸지 않았다.
- 기술적 점수 기반 중·장기 스캐너를 선별적으로 `main`에 추가했다.
  `app.py`에서 **📊 중·장기 투자 스캐너 보기** 링크로 접근한다.
- 운영 공통 지표에 없던 OBV 5·20일 특징값만 추가하고
  단기 RSI 등 기존 필드 계산은 유지했다.
- 운영 실행 검증: 한국 종가매매 **495개 종목**, 과거 손상 구간 이후
  최근 일봉으로 분석 가능한 45개 포함, 4개 제외. 오늘~3일 전
  **4개 탭** 정상.
- 중·장기 규칙 기반 스캐너: 한국 **490개**, 미국 **66개**를
  **1·3·6·12개월 기간별로 모두 정상 분석**.
- 해외 파일 **81개**, 저장 해외 추천 가격 **56개 행**을
  종목별 실제 일봉과 교차 검증했다.
- 미래 가격 오염 및 다른 종목 열 혼합 검사는 유지했다.

### 3. 수급·CVD의 실제 사용 범위

- 외국인·기관 순매수는 KRX 인증 연결이 여전히 검증되지 않았다.
  대체로 사용자가 공급원과 정확성을 확인한 CSV를 직접 올리는
  **수동 분석 화면**을 중·장기 스캐너에 제공한다.
- 수급 CSV 필수 열: `date,symbol,foreign_net_krw,institution_net_krw`.
  날짜는 신호일 이후를 자동 제외하고, 종목 코드는 6자리,
  금액은 원 단위이다. 자료가 없는 종목을 순매수 0원으로 표시하지 않는다.
- **CVD는 실제 체결 주도 매수/매도 방향**이 포함된 CSV일 때만 분석한다.
  필수 열: `timestamp,volume,aggressor_side`. `timestamp`는
  타임존이 포함된 시각, `aggressor_side`는 buy 또는 sell이다.
  일반 일봉 OHLCV·OBV만으로 CVD를 생성하지 않는다.
- CSV 수동 분석으로 자동·실시간 수급 데이터 피드가 완성된 것은 아니다.

## 여전히 미완료인 외부 의존성·검증

1. **과거 한국 일봉 49개 파일**의 비정상 기록은 출처별 가격 기준,
   액면분할, 거래정지 등과 대조가 필요하다. 자동 임의 보정 금지.
2. **KRX 외국인·기관 자동 조회**는 인증 및 승인된 API 접근이 필요하다.
   허가받은 계정이 있다면 자격증명은 GitHub Secrets에서 관리한다.
   채팅·코드에 비밀번호를 입력하지 않는다.
3. **진짜 자동 실시간 CVD**는 체결 주도 방향이 포함된 라이선스 데이터
   공급원이 필요하다. 현재는 수동 업로드 기능만 있다.
4. **1·3·6·12개월 상승확률 AI 연구 모델**은 Brier 점수 기준 단순
   고정확률 모델보다 일관되게 낫지 않아 운영에 반영하지 않았다.
   규칙 기반 점수를 실제 상승 확률이라고 표시하지 않는다.
5. GitHub 검사와 Streamlit 실제 호스팅 브라우저의 시각/사용성 QA는
   서로 다르다. 저장소 코드 테스트 통과만으로 실제 브라우저
   화면의 모든 기능을 확인했다고 주장하지 않는다.

## 안전한 운영 원칙

- `main`과 `accuracy-lab` 전체 브랜치를 병합하지 않고,
  확인된 코드와 자료만 선별 반영한다.
- 원천 시세 파일과 거래소 인증 정보는 임의로 덮어쓰거나 노출하지 않는다.
- 새로운 매매 AI/수급 지표가 자동으로 추천 점수를 바꾸지 않도록 분리한다.
- 단순 과거 백테스트의 평균 수익률은 실제 체결 수익률이나 보정된 확률이 아니다.
