종가매매 AI 스캐너 v3

실행 방법
1. start_scanner.bat 더블클릭
2. 브라우저에서 화면 확인
3. 표에서 종목 행을 클릭하면 오른쪽 차트와 아래 분석 카드가 바뀝니다.

v3 변경점
- 유튜브 참고 화면처럼 좌측 신호표 + 우측 대형 캔들차트 구조
- 색상 강조, 사이드바, 신호점수/거래대금 표시
- 선택 종목 기본정보 / AI 분석 / 스캐너 상태 / 매매 참고 가이드 카드
- 1차/2차 참고선을 +10% / +20%로 변경
- 검증되지 않은 과거 적중률 숫자는 의도적으로 표시하지 않음

주의
모델 점수는 실제 상승확률이 아닙니다.
+10%, +20%, -3% 가격은 모델 예측값이 아닌 기계적 참고선입니다.
