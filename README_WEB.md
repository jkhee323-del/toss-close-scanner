# 종가매매 AI 스캐너 - 웹 배포용

Streamlit Community Cloud 배포용 패키지입니다.

- Main file: `app.py`
- Python dependencies: `requirements.txt`
- `data/history`, 모델 파일, 한국 종목 데이터 포함
- 로컬 Windows용 `start_scanner.bat`도 남아 있지만 웹 배포에는 사용하지 않습니다.

## Streamlit Community Cloud
1. 이 폴더의 **내용물 전체**를 GitHub 저장소 루트에 올립니다. (폴더 자체를 한 단계 더 중첩하지 않음)
2. Streamlit Community Cloud에서 저장소를 선택합니다.
3. Main file path를 `app.py`로 지정합니다.
4. Deploy 합니다.
