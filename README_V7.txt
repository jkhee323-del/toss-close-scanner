종가매매 AI 스캐너 v7

핵심 수정
1. 한국 종목 검색은 로컬 universe.csv를 우선 사용합니다.
   - 삼성전자 / 005930 검색 시 인터넷 종목목록 조회를 기다리지 않습니다.
   - 검색 버튼을 누르면 선택 상태를 저장한 뒤 즉시 화면을 다시 그립니다.
2. 해외주식 탭 진입과 해외 전체 추천 스캔을 분리했습니다.
   - 해외 탭을 누르는 것만으로 30여 종목을 자동 다운로드하지 않습니다.
   - '해외 추천 새로 분석'을 눌렀을 때만 후보를 새로 계산하고 data/global_candidates.csv에 저장합니다.
3. 해외 직접 검색은 전체 추천 스캔과 분리했습니다.
   - NVDA 등을 검색하면 그 1종목만 받아서 즉시 분석합니다.
4. 해외 추천 결과는 저장되므로 다음 해외 탭 진입 때 다시 전체 다운로드하지 않습니다.

주의
- 해외 후보점수는 현재 기술지표 기반 후보점수이며 실제 상승확률이 아닙니다.
- +10%/+20%는 예측 목표가가 아니라 참고선입니다.
